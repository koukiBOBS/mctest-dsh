# Minecraft Web · 体素沙盒（非官方）

用 three.js 从零实现的 **Minecraft Java Edition 风格**网页体素游戏：程序化无限世界、挖掘与放置、背包与合成、生存/创造、昼夜循环、手机触屏操作。

> ⚠️ 非官方粉丝项目，与 Mojang / Microsoft 无关。仓库内**不包含任何 Mojang 原版素材**，贴图与音效全部由代码程序化生成；想用原版贴图可导入自己的资源包（仅存于本机）。

**在线游玩：<https://koukibobs.github.io/mctest-dsh/>**

## 功能

- **世界**：16×16×128 区块、无限地形，平原 / 森林 / 沙漠 / 雪原 / 山地 / 海洋 / 沙滩生物群系，洞穴、煤/铁/金/钻石矿脉、橡树 / 白桦 / 云杉、仙人掌、花草、黏土、泉水
- **方块**：46 种（新增白桦 / 云杉原木与木板、树叶、仙人掌、黏土块、熔炉、箱子、床、耕地、小麦 4 个阶段等）
- **生物**：猪、羊、牛、鸡（白天草地生成；鸡会下蛋，猪/牛/羊会被手持小麦或种子吸引靠近；羊可用剪刀剪毛）；僵尸、骷髅（射箭）、苦力怕（会爆炸破坏地形）、蜘蛛（夜晚生成、白天也会在暗洞穴生成），会追击 / 近战 / 掉落生肉、皮革、骨头、线、火药等
- **光照规则**：敌对生物只在亮度 < 8 的地方生成（火把周围安全）；僵尸和骷髅在露天白天会燃烧受伤
- **生物行为**：蜘蛛会沿墙向上爬；被剪毛的羊会吃草快速长回羊毛；僵尸会主动追猎村民并攻击（村民受击逃跑）
- **水流动**：放置水源会向四周扩散 7 格（每格衰减一级），从高处流下；挖掉水源后会逐格干涸；水流到岩浆上会把岩浆变成圆石
- **战斗**：左键攻击，木/石/铁剑与斧的伤害、击退、受伤闪红、死亡掉落；**弓与箭**（3 木棍 + 3 线合成弓，燧石 + 木棍 + 羽毛合成箭，按住右键蓄力、松开射出，蓄力越满伤害越高，命中生物有击退）；苦力怕爆炸会破坏方块并造成范围伤害
- **掉落物**：破坏方块 / 生物死亡后掉落物会浮在地面旋转、靠近自动拾取
- **光照**：火把、荧石、岩浆作为光源参与方块光传播（0–15 级），会照亮洞穴、夜晚地面和生物；光源与光照会随存档保存
- **结构**：村庄（6 栋木板/圆石房屋、玻璃窗、门洞、碎石路、中心水井）、地牢（地下石砖房间 + 带战利品箱子）、废弃矿洞（地下矿道网络、木板地面、原木支柱与横梁），沙漠神殿（砂岩阶梯金字塔 + 中空房间 + 双宝藏箱）、雪屋（雪块圆顶小屋 + 宝藏箱）、地下要塞（石砖大厅 + 十字走廊 + 四个端厅 + 末地传送门框架与宝箱）；`/locate village|dungeon|mineshaft|temple|igloo|stronghold` 可定位
- **地牢刷怪**：靠近地牢时每 6 秒会刷出僵尸/骷髅/蜘蛛（创造模式不刷）
- **天气**：晴 / 雨 / 雷暴 / 雪随机切换，雨天天空变暗、雾变近、雨丝粒子、雷暴闪电与雷声、雪天雪花飘落；`/weather rain` 等命令可手动切换，天气会写入存档
- **箱子 / 熔炉**：箱子 27 格存储；熔炉可烧炼矿物与食物（铁矿→铁锭、金矿→金锭、沙子→玻璃、圆石→石头、生肉→熟肉），燃料消耗与燃烧进度条、10 秒/个冶炼；破坏容器会掉出内容物，容器内容随存档保存
- **生存**：徒手/工具挖掘速度、工具等级限制掉落、工具耐久、生命 10 颗心、饥饿条、摔落伤害、岩浆伤害、生肉/苹果/面包回血、树叶掉苹果
- **床**：3 羊毛 + 3 木板合成，右键床在夜晚睡觉跳到清晨，并把出生点设置到床边
- **门**：6 木板合成 3 扇门，放置时按朝向自动对齐；右键开关（薄板模型、开启后可通行）
- **栅栏**：木板 + 木棍合成 3 个，立柱 + 横栏模型，碰撞高度 1.5 格（站着跳不过去），可当围栏使用
- **TNT**：5 火药 + 4 沙子（棋盘格）合成，放置后用燧石右键点燃，2.6 秒后爆炸（威力 4，破坏地形并伤害生物），附近 TNT 会被连锁引爆；苦力怕爆炸也会点燃周围 TNT
- **剪刀与桶**：剪刀（2 铁锭斜排）右键羊剪下 1–3 个羊毛，60–120 秒后重新长毛；桶（3 铁锭）右键水面/岩浆装桶，再右键地面倒出（水流会照常扩散）
- **末影龙 Boss**：进入末地后自动生成末影龙（200 血、屏幕顶部紫色血条），在空中盘旋并周期性俯冲撞击（6 点伤害 + 击退）；击败后获得 80 经验并解锁「屠龙者」成就
- **末地传送门**：地下要塞大厅内有 5×5 框架 + 3×3 末地传送门，走进去即传送到末地（末地石浮岛、虚空、暗紫天空），到达点自带返回传送门；新增「末地之旅」成就
- **下界传送门**：用黑曜石搭 4×5 框架（内部 2×3 空），手持燧石右键黑曜石激活；走进紫色传送门 → 传送到下界（下界岩地形、岩浆海、岩壳顶、暗红雾），返回传送门可回到主世界；新增「下界之旅」成就
- **酿造与药水**：3 玻璃合成玻璃瓶，右键水面装成水瓶；酿造台（3 圆石 + 1 玻璃）右键打开，用水瓶 + 玫瑰/牛肉/羽毛酿造治疗/力量/迅捷药水；右键喝下：治疗恢复 6 血、力量 20 秒攻击 +3、迅捷 20 秒移速 +35%，屏幕中央显示效果倒计时
- **经验与附魔**：挖煤矿/铁矿/金矿/钻石矿（4–8 点）和击杀生物获得经验，HUD 热键栏上方显示经验条与等级（存档保存）；附魔台（1 钻石 + 1 绿宝石 + 4 黑曜石）右键打开，消耗等级为手持工具/武器附魔：效率（挖掘 +35%/级）、锋利（伤害 +1/级）、耐久（概率不减耐久），最高 III 级
- **村民交易**：村庄附近会生成村民，右键村民打开交易界面：8 小麦 → 1 绿宝石、1 绿宝石 → 4 面包、3 绿宝石 → 1 钻石、12 煤炭 → 1 绿宝石（新增绿宝石物品与图标）
- **农业**：木/石/铁锄（右键草地/泥土变耕地）、小麦种子播种、4 个生长阶段（约 20–40 秒一阶段）、成熟后收割小麦 → 3 小麦合成面包；高草也有概率掉种子
- **第三人称**：F5 或 HUD「视角」按钮切换，带方块小人模型、走路摆臂动画、相机防穿墙
- **第一人称手持**：右下角显示当前手持方块/物品，挖掘/放置/攻击时挥动，切换物品栏实时更新
- **手感**：疾跑时视野变宽、受伤屏幕震动、走路时手持物品轻微晃动
- **性能**：自动画质（帧率低于 38 时逐步降低渲染分辨率，恢复后自动升回；也可用 `?quality=0.6` 手动设定）；帧率低于 35 时会自动降低视距（最低 2），恢复后升回设置值；雨雪粒子数量随画质缩放
- **合成**：2×2（物品栏内）与 3×3（工作台）有序/无序配方 + 木板标签（任意木板），木板→木棍→工作台→木/石/铁镐斧锹剑、火把、石砖、箱子、熔炉
- **聊天 / 命令**：T 打开聊天，支持 `/help`、`/gamemode`、`/give`、`/time set`、`/tp`、`/seed`、`/spawn`、`/kill`、`/clear`、`/summon`、`/weather`、`/locate`、`/achievements`
- **成就系统**：26 个成就（木头、工作台、镐子、石器/铁器/钻石、怪物猎人、农夫、床、睡觉、烹饪、村庄/地牢/矿洞/神殿/雪屋、雨天），达成时弹出金色提示并写入存档；`/achievements` 查看进度
- **创造**：全物品面板、双击空格/✈ 飞行、瞬间破坏、无限方块
- **渲染**：面剔除 + 顶点 AO + 烘焙天空光、昼夜循环、太阳/月亮/星空/云层/雾、水面、挖掘粒子、方块裂纹 10 阶段、方块高亮
- **音效**：WebAudio 程序化合成（破坏/放置/脚步/水/受伤/UI/合成/环境风声）
- **手机**：虚拟摇杆、拖动转视角、长按挖掘、放置/跳跃/疾跑/飞行、背包按钮、全屏
- **其他**：本地存档（自动保存每 30 秒）、视距/灵敏度/音量设置、F3 调试信息、可导入原版资源包

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 跳跃 | 空格 |
| 潜行 / 疾跑 | Shift / Ctrl |
| 挖掘 | 按住左键 |

### 手机

- 左下摇杆移动，空白处拖动转视角
- ⛏ 长按挖掘，▣ 放置，↑ 跳跃，» 疾跑，✈ 飞行（创造）
- 点快捷栏切换方块；右上「聊天」「背包」「☰」打开聊天、物品栏、暂停

### 资源包导入（原版贴图）

1. 把 **你自己的** MC Java 版资源包 `.zip`（或若干方块/物品 PNG）放到手机里；
2. 游戏内 设置 → 原版资源包 → 导入资源包；
3. 点「应用并刷新」。贴图只存在本机 `localStorage`，不会上传到仓库。

支持自动映射 `assets/minecraft/textures/block/*.png` 与 `item/*.png` 中的 35 个方块贴图、18 个物品图标（含 `grass_block_top`、`poppy`、`short_grass`、`white_wool`、`bricks` 等新旧文件名）。

## 本地运行

```bash
git clone https://github.com/koukiBOBS/mctest-dsh.git
cd mctest-dsh
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

没有构建步骤，直接打开静态服务器即可（需要支持 ES module + importmap 的现代浏览器，Chrome / Edge / Safari 16+）。

## 技术实现

- three.js r160（本地 vendor，importmap 引入）
- 原生 ES modules，无打包器
- 区块 `Uint8Array(16×16×128)`；网格构建时面剔除、顶点色 AO、烘焙天空光；透明/液体/植物分层材质
- 贴图图集：纯 Canvas 2D 程序化生成 8×8 图集（35 个 16×16 贴图 + 裂纹 10 阶段 + 18 个 32×32 物品图标）
- 世界生成：多层 Perlin 噪声（地形/丘陵/温度/湿度/洞穴）+ 整数哈希（矿石/树木/花草），确定性可复现
- 存档：种子 + 玩家改动块 + 玩家状态 + 背包，序列化到 `localStorage`
- 资源包：fflate 解压 zip + PNG 解码缩放，IndexedDB 无关，仅 localStorage

## 已知限制

不是 1:1 复刻：暂无村民、红石、多人联机、下界/末地、附魔、酿造等；光照为简化版亮度传播（没有完整的光照等级贴图/平滑插值）；生物模型为低多边形方块风格；存档在浏览器本地，清缓存会丢失；手机性能有限，视距建议 2–3 区块。
